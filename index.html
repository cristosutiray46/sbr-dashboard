Kendali

Tahan tombol = robot bergerak; lepas = vsp 0. Dashboard mengirim ulang vsp tiap 100 ms.

Parameter PID

Awal = 0 (motor tidak bergerak). Konvensi tanda: θ positif = miring ke belakang, jadi Kpv dan Kiv diisi NEGATIF; Kpa, Kia, Kda, Kps positif.
Kdv = 0, Kis = 0, Kds = 0 (tetap di firmware, sesuai Pers. 3.2 dan 3.6). Nilai tersimpan di robot saat motor mati.
